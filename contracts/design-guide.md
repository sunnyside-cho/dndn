# design-guide (SSOT)

> 계약서. 세션(오케스트레이터)이 사용자와 합의 후 작성·수정한다 — 구현(task-agent·세션)은 준수
> 대상이며 직접 수정하지 않는다(불일치는 완료 보고에 명시). 포맷·규율: `contract-authoring` 스킬.
>
> 전사 표준은 `ax-wireframe` 스킬(HCG AX Mono)이다. 이 문서는 그 표준 위에 얹는 **dndn
> 프로젝트 구체값·오버라이드**만 기록한다. 여기 없는 것은 전부 ax-wireframe 을 따른다.

## 토큰 (CSS 변수 — `app/globals.css` 에 정의, 하드코딩 금지)

AX Mono `:root` 토큰(ink 스케일·역할·radius·spacing·모션·focus-ring)을 **그대로 주입**한다.
색상은 순수 무채색 — 포인트 컬러 금지, 판정·강조는 크기·굵기·면(inverse)으로 표현한다.

### 시니어 UX 오버라이드 (F-06 — 5060 타겟, 사용자 기획서 합의값)

| 항목 | AX 기본 | dndn 값 | 근거 |
|---|---|---|---|
| 본문 기본 크기 | 16px (`.t-body`) | **18px / line 30px** (body 기본값) | F-06 "기본 18px+" |
| 작은 본문 하한 | 14px | **16px** — 14px 미만은 캡션(메타)에만 | 가독성 |
| 버튼 높이 | 모바일 ≥48 | **모든 뷰포트 ≥48px** (주요 CTA 56px) | F-06 "버튼 48px+" |
| 입력 높이 | — | **≥56px, 글자 20px** (숫자 입력 중심) | 문답형 폼 |
| 본문 색 | `--text-secondary #4D4D4D` | 동일 (대비 7.5:1) — `#767676` 은 캡션 전용 | 고대비 |
| 메뉴 | — | **1뎁스 고정** (GNB: 도구 5 + 가이드 + 소개) | F-06 |

## 고정 컴포넌트 (BUILD_BRIEF 공통 컴포넌트 — `apps/web/components/`)

| 컴포넌트 | 규칙 |
|---|---|
| `ResultCard` | 판정 헤드라인(`.t-h2`+`--text-primary`) → 금액 강조(`.t-display` 급) → 근거 접기(`<details>`) → 공유·이미지저장·인쇄 버튼 행. 캡처 대상 영역에 `data-capture` 속성 |
| `SourceBadge` | `기준일 {asOf} · 출처 {기관}` — rules `_meta` 에서 자동, 수기 금지. `.t-caption`, 전 도구·글 하단 |
| `FaqBlock` | 질문형 H2 + `<details>` 직답. 서버렌더 필수(citable). 펼침 시 `faq_open` 이벤트 |
| `Disclaimer` | "본 계산은 참고용이며 법적 효력이 없습니다" + 도구별 문구. `--surface-subtle` 면 |
| `AffiliateSlot` | 12월까지 `enabled=false` (렌더 안 함). 활성 시 "광고" 라벨 내장 — 라벨 없는 변형 금지 |
| `AdSlot` | 승인 전엔 **높이 0으로 접힘**(빈 공간·화면 밀림 금지). 예약 위치만 마크업 |

## 레이아웃

- 콘텐츠 컨테이너 최대 720px(도구·글 — 문답형 단일 컬럼), 홈·목록은 1440 그리드.
- 모바일 우선(360 기준) — 5060 대부분 모바일. 문답형: 한 화면에 한 질문, 큰 [다음] 버튼,
  항상 [뒤로] 제공, 진행 표시(n/전체).
- 다크모드: AX `[data-theme="dark"]` 역할 토큰 반전 그대로. 시스템 설정 따름(토글 없음 — 단순성).

## 문구 톤

- 존댓말, 전문용어는 쓰되 바로 아래 한 줄 쉬운 설명("소득인정액 = 소득과 재산을 월 소득으로
  환산해 합친 금액이에요").
- 단정 금지 영역: verified≠official 값, 국민연금 연계감액 초과 구간 → "~일 수 있어요" + 공단
  확인 안내. 금융상품 직접 추천 문구 금지(금소법 — AffiliateSlot 승인 문구만).
