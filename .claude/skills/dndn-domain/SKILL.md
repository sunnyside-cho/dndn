# dndn 도메인 규칙

> 기획 SSOT: `D:\99_Etc\100_dndn\01_plan\` (PRD·FEATURES·BUILD_BRIEF·WORKFLOW·TOOL_SPEC 5종).
> 이 스킬은 구현 시 절대 어기면 안 되는 불변 규칙만 추린다. 문서상 기한(주차·날짜)은 무시한다.

## 신뢰 규칙 (제품의 존재 이유 — 위반 = 제품 훼손)

1. **제도 숫자 하드코딩 금지.** 선정기준액·요율·공제액 등 모든 제도 수치는
   `apps/web/data/rules/*.json` 에만 존재한다. 엔진·컴포넌트에 숫자 리터럴로 넣지 않는다.
   (개정 = 파일 교체만으로 끝나야 하며, 이를 검증하는 테스트가 DoD.)
2. **모든 수치는 출처·기준일 동반.** rules 의 `_meta.asOf`·`source` 가 SourceBadge 로 전 페이지
   하단에 자동 표기된다. 수기 날짜·수기 출처 금지.
3. **verified 등급 규율**: `official`(원문 확인)만 단정 표현 가능. `check` 는 화면에서
   "재확인 중" 단서 또는 보수적 문구, `todo` 는 해당 기능 단정 금지(범위 표시·공단 확인 안내).
4. **입력값 서버 전송 금지 (F-10).** 소득·재산 입력은 브라우저 안에서만 계산. 폼 데이터를
   fetch/analytics 파라미터에 싣지 않는다 (GA4 이벤트에는 tool/channel 등 메타만).
5. **면책 필수.** 모든 도구 결과에 Disclaimer("참고용, 법적 효력 없음" + 도구별 문구 —
   기초연금은 "실제 수급은 공단 심사에 따름").

## 법적 경계 (금소법·표시광고법 — 위반 = 계정·사업 리스크)

6. **금융상품 직접 추천 문구 금지.** "이 상품이 제일 좋다" 류 금지. 제휴는 플랫폼 승인 문구만,
   "광고" 라벨 필수 (AffiliateSlot 에 내장 — 라벨 없는 변형 금지).
7. **AffiliateSlot 은 12월까지 비활성**(렌더 안 함). AdSlot 은 승인 전 높이 0.
8. **투자 추천·종목 언급 금지** (PRD Non-Goal).

## 계산 도메인 불변식 (TOOL_SPEC 정본)

9. **기초연금 (F-01)**: 소득평가액 = 0.7×max(근로−공제116만,0) + 기타소득(이자는 −4만) [+무료임차].
   재산환산 = max(일반재산−지역공제,0)+max(금융−2천만,0)−부채 를 max(…,0)×4%÷12 + 고급차·회원권 100%.
   임차보증금은 95% 반영(5% 공제 — rules.rentDepositRate, REVIEW C-2 정정. ~~50%~~ 는 스펙 오류였음).
   국민연금 월액 > 기준연금액×150% 이면 **감액 가능성으로만 표시**(A급여
   필요 — 단정 금지). 부부 각 20% 감액, 소득역전방지 최저 = 기준연금액×10%.
10. **퇴직소득세 (F-02)**: 근속공제→환산급여(÷근속×12)→환산급여공제→과세표준→기본세율→÷12×근속.
    근속 1년 미만 올림. 지방소득세 10%. IRP 연금수령 감면: 10년 이하 70%·10~20년 60%·20년 초과
    50% 부담 (2026 신설 50% 는 강조 소재). 일시금 인출 시 감면 소멸 경고 필수.
11. **피부양자 (F-03)**: 사업자등록+사업소득 → 즉시 탈락(500만 특례 없음). 주택임대소득 → 금액
    불문 탈락. 연소득 2,000만 초과 탈락 (공적연금 **100%** 반영 — 부과 시 50%와 다름, 혼동 금지).
    재산: 과표 5.4억 이하 통과 / 5.4~9억은 연소득 1,000만 이하만 / 9억 초과 탈락.
    부부는 **소득요건 모두** 충족 필요(재산은 각자).
12. **4대보험 (F-04)**: 국민연금 기준소득월액 상하한 적용, **60세 이상 국민연금 공제 0**.
    장기요양 = 건보료×0.9448/7.19. 미발표 연도 값은 null → "12월 발표 예정" 표시(추측 금지).
13. **검증 대조 (DoD)**: 기초연금=복지로, 퇴직세=홈택스, 피부양자·보험료=건보공단, 4대보험=4insure
    모의계산과 케이스 대조. 오차 발생 시 원인을 엔진 주석에 문서화.
